# Vitality Orthopedics: Two-Door landing pages, design review

A review copy of a proposed redesign of the nine Two-Door landing and follow-up pages. Open `index.html` (or the GitHub Pages
site for this repo) to flip through the pages on desktop and mobile; `compare.html` shows before and after screenshots.

- The surveys, the booking calendar and the guide form are still images here, and the page buttons do nothing, so nothing can be
  submitted or booked.
- Every page carries noindex meta tags. This is a working copy for the team, not a live site.
